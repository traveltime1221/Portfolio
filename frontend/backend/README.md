v18.20.4

## 安裝與打包
### 安裝依賴

```sh
npm install
```

### 環境設定
參考 [vite 官方 環境設定](https://vite.dev/config/).


### 啟動開發環境

```sh
npm run dev
```

### 打包

```sh
npm run build
```

### [ESLint官網](https://eslint.org/)

```sh
npm run lint
```
